# TWOGETHER

## 🎮 ゲーム概要

**TWOGETHER（トゥギャザー）**は、オンライン・ソロのどちらでもプレイ可能な、ステージ選択型の協力アクションゲームです。

プレイヤー同士で協力しながら、ステージに用意されたさまざまなギミックを突破し、クリアを目指します。

### 基本情報

* **ジャンル**：協力アクションゲーム
* **対応人数**：1～2人
* **プレイ方式**：オンライン / ソロ
* **対応環境**：PC
* **操作方法**：キーボード / コントローラー

---

## 💡 コンセプト

### 老若男女問わず、人数を問わずにプレイできる簡単な協力アクションゲーム

ゲームに慣れていない人でも遊びやすいように、シンプルな操作と短時間で遊べるステージを採用しています。

2人で協力して遊ぶだけでなく、1人でもプレイできるようにすることで、プレイ人数に左右されず楽しめるゲームを目指しています。

## 🧩 主な実装

### 🌐 Photon Fusionによるオンライン接続

Photon Fusionを使用してオンラインマルチプレイを実装しています。

* 1人でも2人でもルームに入室可能
* プレイヤーの接続・切断に対応
* オンライン上でプレイヤー同士が協力してプレイ可能

---

### 🎙️ Photon Voiceによるボイスチャット

Photon Voiceを使用したゲーム内ボイスチャットを実装しています。

#### ミュート機能

* **Mキー**でボイスチャットのミュート / ミュート解除

#### 距離に応じたボイスチャット

通常時は、プレイヤーを中心とした**半径5m以内**にいるプレイヤーにのみ音声が届きます。

また、プレイヤーとの距離に応じて音量が変化します。

* プレイヤーに近い → 声が大きく聞こえる
* プレイヤーから遠い → 声が小さく聞こえる
* 5m以上離れる → 音声が届かない

#### トランシーバー

ステージ内に存在する「トランシーバー」を所持することで、通常の距離制限を無視してボイスチャットを行うことができます。

* **Tキーを押している間のみ有効**
* トランシーバー所持中は、離れたプレイヤーとも会話可能

---

### 🧩 多様なギミック

ステージ内には、プレイヤー同士の協力が必要となるさまざまなギミックを実装しています。

例：

* とらばさみ
* 落とし穴
* 感圧板
* 転がる岩
* 2人用ドア
* その他多数のギミック

ギミックやマップの情報はCSVを利用して管理しています。

---

### 🤖 NPCによるプレイヤー代替

1人でプレイしている場合や、協力プレイヤーが途中で切断した場合には、NPCが生成されます。

NPCはプレイヤーと同じようにステージ内を行動することができます。

また、プレイヤーからスタンプを送ることで、NPCに簡単な指示を出すことができます。

これにより、**2人プレイを前提としたステージでも、1人でゲームを進行できる仕組み**を実現しています。

---

### 📊 ログ機能

ゲーム中のプレイヤーの行動やステージの状況を記録するログ機能を実装しています。

#### 記録される主な情報

1. ゲーム開始・終了時刻
2. 各ギミックが動作したタイミング
3. プレイヤーがゲームオーバーになったタイミング
4. プレイヤーがゲームをクリアしたタイミング

また、これらのログには以下の情報も記録されます。

* どのプレイヤーか
* どのマッチか
* ゲーム開始からの経過時間
* プレイヤーの現在地の座標

プレイヤーの座標については、**0.5秒ごと**に記録しています。

---

### 🗺️ ステージ制

複数のステージからプレイするステージを選択できます。

現在は**約8ステージ**を用意しています。

各ステージには異なるギミックやマップが用意されており、ステージごとに異なる攻略が必要になります。

---

### 🗺️ CSVによるマップ生成

ステージのマップ情報をCSVで管理し、CSVのデータをもとにマップを生成するシステムを実装しています。

これにより、Unity上で直接マップを作成するだけでなく、CSVを編集することでステージの構成を変更できるようにしています。

---

### 💬 スタンプ機能

プレイヤー同士のコミュニケーションや、NPCへの指示に使用できるスタンプ機能を実装しています。

特にソロプレイ時には、スタンプを利用してNPCへ簡単な指示を出すことができます。
